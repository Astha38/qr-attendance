# 📱 Real-Time QR Code Attendance System

A modern, secure, and real-time attendance system utilizing dynamic QR codes. Teachers can create sessions and generate QR codes that automatically rotate to prevent attendance fraud (like sharing screenshots), while students scan/input the details to mark attendance. Real-time statistics are immediately broadcast to the teacher's dashboard .

---

## ✨ Features

- **🔄 Dynamic QR Code Rotation**: The QR code automatically rotates/updates every 30 seconds to prevent students from sharing QR code screenshots with peers outside the classroom.
- **⚡ Real-Time Broadcasting**: Uses **Socket.io** to instantly stream attendance updates to the teacher dashboard as students mark themselves present.
- **🔒 Anti-Fraud / Duplicate Prevention**: Ensures each student can only mark their attendance once per session via database constraints (`UNIQUE(session_id, student_name)`).
- **📂 Persistent Database Storage**: Powered by an **SQLite3** database that persists all sessions and attendance records.
- **🎨 Modern, Responsive Design**: A beautifully crafted UI/UX with smooth transitions, modern typography, glassmorphic elements, and user-friendly states for both desktop and mobile screens.

---

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Real-Time Communication**: Socket.io
- **Database**: SQLite3
- **QR Code Generation**: `qrcode` npm package
- **Frontend**: HTML5, Vanilla CSS3 (Custom design system), JavaScript (ES6+)

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/Astha38/qr-attendance.git
   cd qr-attendance
   ```

2. Install the required dependencies:
   ```bash
   npm install
   ```

### Running the Application

1. Start the server:
   ```bash
   npm start
   ```

2. The server will launch at:
   👉 **http://localhost:3001**

## 📖 How it Works

### 👨‍🏫 Teacher Workflow
1. Navigate to the main page (defaults to `/teacher.html`).
2. Log in with a teacher account (e.g., username: `astha492`, password: `123`).
3. Enter the class name (e.g., *Computer Networks*) and click **Create Session**.
4. Click **Start Session** to activate the session. The dynamic QR code will appear and automatically rotate every 30 seconds.
5. Watch the attendance list populate in real-time as students scan the QR code.

### 🧑‍🎓 Student Workflow
1. Navigate to `/student.html`.
2. Log in with a student account (e.g., username: `alice`, password: `student1`).
3. Scan the QR code (or enter the session ID and active token generated by the teacher's screen).
4. Click **Mark Attendance**. If successful, the student's status changes to green, and their name instantly shows up on the teacher's dashboard.
